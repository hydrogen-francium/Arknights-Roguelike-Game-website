# Context（上下文）

适用于赛事官网后台登录页，静态文件由 `server.mjs` 直接提供，登录表单由 `admin.js` 监听 `submit` 事件并调用 `/api/session`。

# Fact / Pitfall（事实或坑点）

后台登录按钮点击无响应时，不能只判断账号密码是否错误。浏览器可能继续使用旧版 `admin.html` 或 `admin.js`，导致页面没有加载当前提交处理逻辑；如果脚本解析失败，表单也不会发起请求。

# Solution / Convention（解决方案或规约）

- 后台脚本入口使用带版本查询参数的路径，例如 `admin.js?v=20260927-1`，发布脚本修改后递增版本。
- `sendStaticFile` 对 HTML、JavaScript 等静态响应发送 `cache-control: no-store`，避免部署后继续使用旧脚本。
- 登录提交处理器必须显式读取用户名和密码，调用 `fetch('/api/session')` 时声明 `credentials: 'same-origin'`，并在请求期间禁用按钮；请求失败或进入后台失败时通过现有错误区域显示错误，并在 `finally` 中恢复按钮状态。
- 修改部署后，首次打开后台应执行一次强制刷新（Windows 使用 `Ctrl+Shift+R`），用于清除此前已缓存的旧后台入口页。
