# 积分明细栅格布局

## Context（上下文）

积分数据展开面板使用“标签 + 数值”的逐行结构，并允许插入分组标题。

## Fact / Pitfall（事实或坑点）

如果容器使用三列 CSS Grid，而模板实际只输出“规则文本 + 数值”两列，浏览器会把下一条规则文本推入第三列，随后数值换到下一行，最终造成截图中标签和值错位、出现大片空白。

## Solution / Convention（解决方案或规约）

`.score-ledger` 必须使用两列：第一列放规则文本，第二列放数值；分组标题通过 `grid-column: 1 / -1` 横跨整行。移动端只调整两列比例，不再增加隐含列。
